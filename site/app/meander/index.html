You've reached Meander, a minimal, frame-based web stumbler for sites I personally recommend.

Meander the Web (HTTPS)

The only hard-and-fast criterion for inclusion is that I liked it, but there is a strong emphasis on independent and personal sites. I started with my RSS subscriptions, removed everything hosted on Substack, then started adding links: small websites I've found recently, web 1.0 gems, short fiction, random stuff I think is cool and should be better-known. I intend this to be a replacement for a blogroll, linkdump, etc. Here's the list (text) and here are sites I wanted to include but can't (text).

# Web Applications #
#code

- [[maRRRshmallow breath counter|/app/rrr/]]: a simple **JavaScript** tool for measuring my cat's resting respiratory rate.
- [[nagi miniweb|/app/nagi/]]: minimalist version of [[Kagi Small Web|https://kagi.com/smallweb]]. An experiment in brute force. Intended to enable pre-js, pre-https access, but currently depends on frameset support and uses a [[dataset|https://github.com/kagisearch/smallweb/blob/main/smallweb.txt]] that is mostly only served over https. **Compatible with links2 and elinks.**

# Web Applications #
#code #project

- [[maRRRshmallow breath counter|./rrr]]: JavaScript tool for measuring my cat's resting respiratory rate.
- [[nagi miniweb|./nagi]]: minimalist version of [[Kagi Small Web|https://kagi.com/smallweb]]. An experiment in brute force. Does not require JavaScript or CSS; does require frames. **Compatible with links2, elinks, and `w3m -F`.** [[Writeup here|2026-04-08_nagi]].
- [[Meander|./meander]]: nagi, but with my personal recommendations as the dataset. Also available as a [[Wander console|./wander]] (requires JS).
- [[Wander Console Builder|./wcb]]: JavaScript tool to simplify creating/updating a [[Wander|https://codeberg.org/susam/wander]] console. Pretty colors!
- [[Build-A-Sophie|./sophie]]: fan-made CSS-based character creator for _Puzzle Castle_, a children's video game from 1996. Includes bonus jukebox feature. JS-free. [[Writeup here|2026-04-26_sophie]].
- [[Noliza|./noliza]]: therapy chatbot that always tells the truth. This cutting-edge AI runs entirely in [[Turing-complete|https://github.com/rebane2001/x86CSS]] CSS.
- [[frameset Sierpińsky carpet|./carpet]]: [[fractal|https://en.wikipedia.org/wiki/Sierpi%C5%84ski_carpet]] made of a single sub-500 byte HTML file. Sadly only gets two levels of recursion in modern browsers and less in old ones. Inspired by the [[Penfield Mood Organ|https://penfield.ily.rs/]] [[challenge|https://ily.rs/blog/penfield/#:~:text=inspired]].

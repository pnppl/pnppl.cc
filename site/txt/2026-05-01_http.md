# Free insecure HTTP hosts
#tech #list

- [[Web 1.0 Hosting|http://web1.0hosting.net/]]
	- Hosts this very website
	- 500MB disk (with forum participation)
	- Custom domains are restricted to sitename.tld, no subdomain support
	- Upload is only clear FTP; no user interface for changing password
	- Extensive retro support
	- Finland
- [[Github Pages|https://pages.github.com/]]
	- Hosts Prairieland Zines
	- Custom domain required for no-SSL access
	- No formal disk limit?
	- U.S. (Microsoft)
- [[AlwaysData|https://www.alwaysdata.com/]]
	- No custom domain on free plan
	- 1GB disk
	- Very generous and featureful — not just static sites
	- France
- [[HelioHost|https://heliohost.org/]]?
	- 1GB disk
	- Registration only opens for like one second every twelve hours; you can jump the line for $2
	- U.S. (nonprofit)
- [[InfinityFree|https://www.infinityfree.com/]]
	- 5GB disk
	- *Very* hostile to non-mainstream browser useragents — curl gets `(52) Empty reply from server` unless I pass `--user-agent "fuck you"`. [[Bear Blog|https://bearblog.dev/]] — another site that engages in useragent discrimination — at least returns a 403.
	- Netherlands
- [[Surge|https://surge.sh/]]
	- No SSL with custom domain on free plan
	- No formal disk limit?
	- PDFs don't seem to be allowed?
	- You have to install nodejs
	- Canada
